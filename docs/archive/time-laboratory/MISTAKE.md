# Mistakes and lessons

This records observed design mismatches and known risks. It is not a claim that an application has already been built or tested.

## M01 — Treating Quantum as an outcome gallery

The initial concept showed eight landscape thumbnails. The user clarified that Quantum must be a **decision tree**, and clicking an instance opens its 4D view.

**Prevention:** verify connected branches, eight terminal outcomes, one selected route, and the selected-history link to the viewport.

## M02 — Treating time as separate landscape islands

The first visual used disconnected valley snapshots. The user supplied an image of repeated objects extending along time to clarify the intended experience.

**Prevention:** show recognizable object histories together in one coordinate space. Time planes support the view; they are not separate world cards.

## M03 — Insufficient dimensionality

The revised diagram still felt too flat; the user requested more 3D.

**Prevention:** validate object volume, perspective, lighting, contact shadows, occlusion, and camera orbit with an actual prototype. A still image cannot prove an interactive scene feels three-dimensional.

## M04 — Trusting generated concept details

Generated references contain route-highlighting and wording inconsistencies. For example, a highlighted path may not connect to the selected leaf, and 'predators persist' is not the same decision as 'remove predators'.

**Prevention:** derive tree wiring and labels from the intervention data, not pixels. Highlight precisely the selected leaf's ancestors.

## M05 — Stretching one creature across decades

The visual concept labels repeated butterflies as the same individual across a 30-year axis. That is an unsupported biological implication.

**Prevention:** annual views use cohort/population markers. Individual views end at death and use an appropriate timescale. Label illustrative movement honestly.

## M06 — Letting the art contradict the model

A lush baseline thumbnail or recovered tree can look attractive while contradicting drought or extinction data.

**Prevention:** derive terrain conditions, vegetation, population marks, evidence, and verdicts from the same simulation snapshots.

## M07 — Losing fair comparison through randomness

Reusing a seed alone is insufficient if interventions change random-call order.

**Prevention:** index climate/random streams independently by process and time. Test branch evaluation order independence and matching historical prefixes.

## M08 — Treating an expanded scope as the original schedule

The original short schedule assumed a simpler 2D world. The newer 3D object-history experience adds asset, interaction, performance, and accessibility work.

**Prevention:** re-estimate after the prototype. Do not promise a competition deadline based on unverified dates from the pasted brief.
