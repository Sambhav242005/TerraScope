# Echoes of Extinction

The current experience is **The Last Glasswing**, one ecological detective mystery in Moonveil Valley. The original investigation plan remains the gameplay foundation: discover five clues, choose an evidence-supported explanation, rewind, test one intervention, compare histories, and deliver a verdict.

## Living 3D Valley enhancement

The latest approved direction upgrades the habitat presentation to a living, orbitable 3D valley with ten recognizable fauna types. This changes the world renderer, not the investigation sequence. There are no Quantum branches, intervention combinations, object time tunnels, or simultaneous time-history scenes. The former time laboratory remains historical material under `docs/archive/time-laboratory`.

The browser-only demo uses React, TypeScript, a deterministic ecological model, local progress saving, and a 3D habitat renderer with an accessible fallback. No accounts or paid runtime API. The first case targets a 3–5 minute investigation; observed playtime remains to be tested.

Read `DESIGN.md` for presentation, `SPEC.md` for behavior, `TASKS.md` for remaining work, and `README.md` for running and checking the demo. Competition and hosting claims in `docs/original-plan.md` remain unverified. Nothing has been published or submitted.
