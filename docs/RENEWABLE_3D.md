# 3D renewable proposal objects ? 5 November 2026

> Current status (5 November 2026): [Latest delivery, verification and remaining gaps](CURRENT_STATUS.md) supersedes older implementation-status statements below. Earlier dated notes are retained as history. R01-R18 remain active.


Partial R06/R13: procedural Three.js models render in the existing MapLibre WebGL canvas, with geographic metre scale and a shared depth buffer. Solar creates one selectable installation containing 48 instanced, tilted panel tables with cell seams and supports. Each wind placement creates one tower, foundation, nacelle, hub and three-blade rotor. One installation remains one saved intervention and one delete/undo operation; individual solar tables do not become separate proposals.

Visual assumptions: solar footprint follows sqrt(assumed area), tables use 20-degree tilt; wind hub 80 m, rotor diameter 66 m. These are illustrative assets independent of nameplate rating, wind resource, actual equipment or construction drawings. No physics or simulated benefits are added. Blades are static. Existing map pins, keyboard-accessible proposal list, overlap checks and explanations remain available, including top-down view. Clicking a mesh selects its proposal through ray picking. Existing proposals gain visuals automatically after restore. Hide/remove updates dispose geometries, instanced buffers and materials; layer removal disposes the shared-context renderer without forcing context loss. No continuous animation timer/repaint loop is added.

Anchoring uses the map's loaded DEM elevation when terrain is enabled, otherwise zero elevation. This fallback and the illustrative dimensions are disclosed in the view; no foundation or terrain-survey precision is implied. Solar tables share an installation-plane elevation rather than individually surveyed footings. Proposals may visibly overlap water/buildings and retain the automatic conflict warnings; objects do not confer suitability. No physical-phone performance claim; adding Three.js increases the main bundle to about 2 MB minified (545 KB gzip), with the existing bundle warning.

Documentation: installed MapLibre 6.16 custom-layer type uses render(gl, options); Mercator-compatible matrix is options.defaultProjectionData.mainMatrix. Official reference: https://maplibre.org/maplibre-gl-js/docs/API/interfaces/CustomLayerInterface/ . Context7 unavailable in this session; installed types and official docs used. No external model/texture assets, new package or licensing requirement was introduced.

Evidence: tests/renewable-models.test.js checks grouping, one-turbine structure and input immutability. tests/renewables-3d-check.mjs exercises actual mesh selection, proposal-list selection, top-down view and deletion with no unhandled page errors. Actual screenshots: artifacts/renewables-3d.png and artifacts/renewables-topdown.png. All 86 unit tests and production build pass; placement-validation browser checks pass. These are rendering/software checks, not energy/yield, wake or environmental model validation.
